# Glossary [DRAFT]

## Game Terms

### Cultivation Terms

| Term | Definition |
|------|------------|
| **Aperture** | The internal space where a cultivator stores Gu. Limited slots expand with rank. |
| **Attainment** | Mastery level in a cultivation path. Levels: Ordinary → Master → Quasi-Grandmaster → Grandmaster → Quasi-Great Grandmaster → Great Grandmaster. Extremely difficult to raise. |
| **Blessed Land** | Personal dimension received upon becoming immortal. Contains resources and time dilation. |
| **Breakthrough** | The attempt to advance from one rank to the next. Can succeed or fail. |
| **Closed Door Cultivation** | Intensive cultivation mode where time accelerates and outside events queue. |
| **Cultivation** | The practice of advancing through ranks using Gu and resources. |
| **Deviation** | Cultivation accident from pushing too hard. Can cause injury or death. |
| **Earthly Calamity** | The tribulation faced when ascending from mortal to immortal (Rank 5→6). |
| **Grotto Heaven** | Stronger version of blessed land. Higher rank immortals possess these. |
| **Immortal** | Cultivator of Rank 6 or above. Significantly more powerful than mortals. |
| **Killer Move** | Combination technique using multiple Gu for amplified effects. Requires Master+ attainment. |
| **Mortal** | Cultivator of Rank 1-5. Has limited lifespan without rank advancement. |
| **Path** | School of cultivation (Fire, Blood, Wisdom, etc.). Determines Gu affinity. |
| **Primeval Essence** | Internal energy used to activate Gu. Regenerates outside combat. |
| **Primeval Stone** | Universal currency for mortals. Used for cultivation and trade. |
| **Rank** | Power level from 1-9. Determines Gu accessibility and abilities. |
| **Tribulation** | Major challenge faced during advancement. Immortals face regular tribulations. |
| **Venerable** | Rank 9 cultivator. The ultimate power level and victory condition. |

### Gu Terms

| Term | Definition |
|------|------------|
| **Gu** | Living magical creature that grants abilities. Stored in aperture. |
| **Gu Formula** | Recipe for creating a specific Gu. Requires materials and refinement. |
| **Gu Master** | Cultivator who uses Gu. Standard term for player character. |
| **Feeding** | Maintaining Gu with resources. Unfed Gu lose effectiveness and may die. |
| **Refinement** | The process of creating or upgrading Gu from materials and formulas. |
| **Slot** | Space in aperture. Each Gu typically takes one slot. |
| **Wild Gu** | Gu found in nature, not yet captured or refined. |

### World Terms

| Term | Definition |
|------|------------|
| **Central Continent** | Region dominated by large sects. Unlockable area. |
| **Clan** | Family-based cultivation group in Southern Border. Starting factions. |
| **Demonic** | Reputation alignment associated with selfish/evil actions. |
| **Northern Plains** | Region of nomadic tribes. Unlockable area. |
| **Righteous** | Reputation alignment associated with honorable actions. |
| **Sect** | Organization-based cultivation group in Central Continent. |
| **Southern Border** | Starting region. Home to the main clans. |
| **Treasure Yellow Heaven** | Immortal-only auction house for cross-region trading. |
| **Tribe** | Nomadic cultivation groups in Northern Plains. |

### Gameplay Terms

| Term | Definition |
|------|------------|
| **Disposition** | NPC attitude toward player. Ranges from Mortal Enemy to Devoted. |
| **Event** | Situation requiring player choice. Generated based on context. |
| **Goal** | Player-set objective that influences event generation. |
| **Inheritance** | Meta-progression system. Knowledge/items passed between runs. |
| **Run** | Single playthrough from character creation to death/victory. |
| **Standing** | Position within a clan. Affects mission access and prices. |

## Source Material Terms

Terms from the Reverend Insanity novel that inform game design:

### Canonical Paths

The novel features many paths. We use 10 main paths:

| Path | Novel Description |
|------|-------------------|
| **Strength Path** | Physical power cultivation |
| **Wisdom Path** | Knowledge and deduction |
| **Blood Path** | Life force manipulation |
| **Refinement Path** | Gu creation and modification |
| **Transformation Path** | Shapeshifting and adaptation |
| **Enslavement Path** | Control and domination |
| **Poison Path** | Toxins and decay |
| **Dark Path** | Shadows and stealth (Shadow Path in novel) |
| **Light Path** | Radiance and protection |
| **Food Path** | Consumption and nourishment |

### Notable Novel Concepts

| Concept | Description | Game Implementation |
|---------|-------------|---------------------|
| **Fang Yuan** | Novel protagonist, ruthless schemer | Player can follow similar path |
| **Spring Autumn Cicada** | Time-reversal Gu | Inspiration for inheritance system |
| **Dao Marks** | Path-specific marks affecting cultivation | Immortal stage mechanic |
| **Immortal Gu House** | Mobile fortress-Gu | Possible late-game content |
| **Fortune Rivaling Heaven** | Luck manipulation | Random number influence Gu |

## Technical Terms

| Term | Definition |
|------|------------|
| **Autoload** | Godot singleton script that persists across scenes |
| **Cache** | Stored generated content for reuse |
| **Fallback** | Pre-made content used when AI generation fails |
| **Generation** | Creating content via AI (Gu, events, NPCs) |
| **Prompt** | Instructions given to AI for content generation |
| **Validation** | Checking AI output meets game rules |
